LOKi: IoT Smart Locker

OngoingGDGoC ITB 2026

A shared smart-locker concept for campus environments, combining a Progressive Web App (PWA), backend authorization, ESP32-based IoT control, electronic solenoid locks, and door-state monitoring.

Problem

Campus users need accessible temporary storage, with locker access that is recorded and secure.

Solution

LOKi is a shared smart-locker concept for campus environments, combining a Progressive Web App (PWA), backend authorization, ESP32-based IoT control, electronic solenoid locks, and door-state monitoring. It aims to make temporary storage more accessible while recording locker access and improving security.
